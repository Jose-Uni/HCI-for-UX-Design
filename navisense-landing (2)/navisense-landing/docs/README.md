# NaviSense – Landing Page (HCI for UX Design 1ASI0784 · 2026-20)

Landing page responsive con panel del cuidador y demos interactivas de la app móvil.

## Estructura
- `pages/index.html` – página principal (`/index.html` en la raíz solo redirige, para GitHub Pages)
- `css/styles.css` – tokens de la guía de estilos (cap. 4.1) y componentes
- `js/main.js` – interacciones, una función por grupo de HU
- `assets/` – imágenes, iconos, fuentes, videos

## Trazabilidad HU → sección
Cada sección del HTML declara las HU que implementa en el atributo `data-hu`.

## Créditos
Equipo NaviSense. Tipografía: Atkinson Hyperlegible (SIL OFL).
